# Sports Feed App

## Overview

The Sports Feed App is an Android application developed in Java using Android Studio. It is designed to provide users with a clean and simple platform to browse sports-related content such as latest match updates, sports headlines, trending news, categories, and score sections. The project focuses on creating an engaging mobile interface while demonstrating Android UI development and screen navigation.

---

## Main Objective

The purpose of this application is to simulate a modern sports information app where users can quickly access sports content in one place. It also demonstrates practical Android development skills including layouts, activities, lists, adapters, and structured project design.

---

## Features

### Home Screen

- Displays sports dashboard layout
- Easy navigation to sections
- Modern sports-themed UI

### Sports Categories

Users can browse categories such as:

- Football
- Cricket
- Basketball
- Tennis
- Other sports

### Feed / News Section

- Latest sports headlines
- Trending sports stories
- Match-related content

### Scores / Highlights Section

- Match score display
- Team highlights
- Quick updates

### Navigation

- Multiple activities/screens
- Smooth transitions using intents

## Key Android Concepts Used

### Activity Lifecycle

Used lifecycle methods such as:

- `onCreate()`
- `onStart()`
- `onResume()`

### RecyclerView / ListView

Used to display dynamic sports content in scrollable lists.

### Adapters

Custom adapters help connect sports data to UI rows/cards.

### Intents

Used to move between screens and pass selected data.
